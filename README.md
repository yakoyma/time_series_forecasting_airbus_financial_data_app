# Project: Airbus Financial Data Forecasting Application

The purpose of this Time Series project is to develop an application able to forecast daily logarithmic returns and estimate volatility based on these forecasts. The goal is to identify and analyse trends, significant fluctuations, and irregularities in the data, as well as estimate volatility. Volatility estimation enables informed decisions to be made regarding risk management and portfolio construction.

The machine-learning models tested are trained on financial data downloaded using the Python library yfinance.



# Projet : Application de prévisions des données financières d'Airbus

Ce projet de séries temporelles vise à développer une application capable de prévoir les rendements logarithmiques quotidiens et d’estimer la volatilité à partir de ces prévisions. L’objectif est d’identifier et d’analyser les tendances, les variations significatives et les irrégularités des données, ainsi que d'estimer la volatilité. L’estimation de la volatilité permet de prendre des décisions éclairées en matière de gestion des risques et de construction de portefeuille.

Les modèles d’apprentissage automatique testés sont entraînés sur des données financières téléchargées à l’aide de la librairie Python yfinance.
